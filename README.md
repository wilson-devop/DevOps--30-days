# My 30-Day DevOps and Cloud Engineering Journey

## About Me
I am an IT student learning software development and working toward becoming a DevOps and Cloud Engineer.

## Why I Chose DevOps and Cloud Engineering
I want to understand how software is built, tested, deployed, monitored, and maintained. I want to develop practical skills that will help me build reliable systems and prepare for internships and future employment.

## Skills I Already Have
- Python fundamentals
- Django REST Framework
- React fundamentals
- PostgreSQL fundamentals
- Basic Linux and Git

## My 30-Day Goals
By the end of these 30 days, I aim to:

1. Improve my Linux command-line skills.
2. Understand Git and GitHub workflows.
3. Build and run Docker containers.
4. Connect a Django application to PostgreSQL using Docker Compose.
5. Create a CI workflow using GitHub Actions.
6. Understand AWS cloud fundamentals.
7. Document a deployment plan and practise deploying an application.

## My Daily Commitment
I will dedicate two hours each day to learning, practising, documenting my progress, and reviewing what I have learned.
